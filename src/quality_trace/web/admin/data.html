导入是唯一能一次写坏主数据表的入口，所以流程被拆成"预览 → 确认"两步： 预览只校验不写库，确认才落库。导出的文件带 UTF-8 BOM，Excel 双击不会乱码。

接口一览（供脚本调用）

端点说明
GET /api/v1/io/datasets可导入/可导出的数据集元信息
GET /api/v1/io/template/{dataset}导入模板下载
POST /api/v1/io/import/preview只校验不落库
POST /api/v1/io/import校验 + 落库
GET /api/v1/io/export?dataset=…&format=…单表导出
GET /api/v1/io/export/bundle三表打包

脚本调用用 Authorization: Bearer <JWT>；浏览器直接下载走 Cookie。
