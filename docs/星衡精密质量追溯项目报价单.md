## 二、项目范围

- 建设内容：**异常定位辅助 + 追溯清单**自动生成，覆盖"首件检验 → 巡检 → 不合格隔离 → 原因分析 → 返工 → 复检"六节点链路。
- 范围红线：不自动认定根因、不自动放行；AI 输出仅为辅助，最终判定由授权岗位签核（依据 f05 / f40 / f52）。
- 实施方式：历史资料回放验证 → 4 周小范围并行试点，不替换现有业务（f05）。

## 五、商务条款

- 本报价为**含税总价**，开具增值税发票；报价有效期 30 天。
- 对外交付范围与验收标准以本报价单第三节交付清单为准；清单外需求走变更流程，累计变更超合同额 20% 触发合同重谈。
- 试点评价与操作记录留存 90 天，期满由产品安全负责人复核删除或归档（f43）。
- AI 输出仅为异常定位辅助与追溯清单，不构成根因认定或放行依据；涉及放行结论须经对应审批人签核（f05 / f40 / f41 / f52）。
- 触及停止条件（返工换批号追不到原刀具、资料缺依据、两版本冲突、关键系统不可用）即转人工，并标注触发原因、接手人、确认时间（f44）。
- 首期含 3 个月运维；期满后可选订阅 3,000 元/月，随时终止。

## 六、验收标准

- 两类零件试点、批次追溯完整率 **99%**、错误放行为**零**（f02 / f42）；
- 缺陷定位从 **2 天缩短至 4 小时**（f00）；
- 返工环节强制保留原业务编号，换批号不丢追溯链（f11 / f23）；
- 人工兜底与审计留痕全覆盖，任一不可逆动作前有具名签核（f40 / f45）。
